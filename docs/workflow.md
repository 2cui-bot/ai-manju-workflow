# 通用 AI 漫剧工作流（适用于任何题材）

> 来源：一部 AI 短片从零到成片实际跑通的流程，去掉题材部分，抽象成通式。
> 标 ✅ 的环节在实际项目里验证过；标 ⚠️ 的是通用做法、尚未实测（例如口型同步），用之前先小额试一次。

---

## 0. 核心原则（任何题材都适用）

1. **先文字、后图片、再视频**。越往后越贵、越难改，所以问题要在前面的环节解决。
2. **一致性靠"资产"保证，不能只靠提示词**。人物、场景、画风先做成固定的参考图和固定的文字段落，后面每次都原样复用。
3. **视频模型只负责"让画面动起来"**。画面里有什么，由首帧（和尾帧）决定；运动提示词只写怎么动。
4. **每个镜头只放 1–2 个动作**。动作越多，越容易崩。
5. **花钱的步骤之前设关卡**：先审核、再报价、获批后才提交；一次先试一镜。
6. **能靠剪辑修的就不重拍；必须重拍时，一次只重拍一镜。**
7. **版本只增不覆盖**，每一步都写进度文件。

---

## 1. 总流程

```
A 立项规格
B 剧本层：世界观圣经 → 分集大纲 → 单集剧本
C 资产层：画风定稿 → 角色设定卡 → 场景设定卡 → 道具卡
D 分镜层：镜头表 → 色块草图/构图检查
E 静帧层：每镜首帧（+尾帧） → 自动检查 → 独立审核
F 动态层：报价获批 → 图生视频 → 逐帧审片 → 必要时重拍
G 声音层：配音/对白 →（口型同步）→ 配乐卡点 → 音效
H 合成层：剪辑 → 字幕 → 混音 → 导出 → 封面
I 复盘：踩坑记录 → 更新模板
```

一部多集漫剧的节奏是：**A、B 的世界观、C 只做一次**；从 B 的单集剧本开始，到 H，每一集循环一遍。

---

## A. 立项规格（开工前一次定死）

| 项 | 怎么定 | 常见取值 |
|---|---|---|
| 平台/画幅 | 竖屏短视频平台用 9:16，横屏用 16:9 | 漫剧多数是 9:16，1080×1920 或 720×1280 |
| 单集时长 | 平台习惯 | 1–3 分钟/集；每集 15–40 镜 |
| 每镜时长 | 模型能稳定生成的长度 | 3–6 秒；生成时多留 1 秒余量 |
| 画风 | 题材决定（见附录 2） | 2D 漫画 / 3D 动画 / 写实 CG / 国风水墨 |
| 声音 | 对白、旁白、配乐、音效 | 对白多就要考虑口型同步 |
| 预算 | 按公式估算（见 F） | 先算出每集成本，再决定用什么模型 |
| 合规 | 平台审核、版权 | 不用真人脸、不仿现成 IP、音乐用公有领域或已授权的 |

**预算公式**：
```
单集成本 ≈ 镜头数 × (首尾帧张数 × 单张价 + 每镜秒数 × 每秒视频价) × (1 + 重拍率)
重拍率经验值：按 30% 预留
```

## B. 剧本层

### B1 世界观圣经（全剧只写一份）
- 一句话卖点、题材、基调
- 时代/地点/规则（魔法体系、科技水平、社会背景）
- 主要角色关系图
- 视觉关键词（3–5 个形容词，后面直接用到画风段里）

### B2 分集大纲
每集写：本集目标 → 冲突 → 反转 → **结尾钩子**。

### B3 单集剧本：漫剧节奏模板
| 时间点 | 作用 |
|---|---|
| 0–3 秒 | **钩子**：冲突画面、反常的事，或一句狠台词 |
| 前 15 秒 | 交代人物和处境（一个镜头只交代一件事） |
| 中段 | 每 15–20 秒出现一个小反转或情绪点 |
| 最后 5 秒 | 悬念或反转，留下追更的理由 |

### B4 AI 可拍性改写（剧本定稿前必须过一遍）
- 每镜每人最多 1–2 个动作；配角最多 1 个
- 少写：打斗交缠、拥抱、多人互动、手部特写、快速运镜、画面里的文字（招牌、书信、屏幕）
- 必须要的复杂动作，拆成多个镜头，用剪辑来表现
- 对白镜头尽量拍侧脸、背影、远景，或者用"画外音 + 反应镜头"，可以避开口型问题
- 每镜都写清楚**首帧是什么样子**

**关卡：剧本没确认之前，不画图。**

---

## C. 资产层（一致性的根本，最值得花时间）

### C1 画风定稿
同一个场景出 3–4 种画风样帧，选一种，然后写成**固定画风段**（全剧原样复用）：

```
STYLE = "Style: <媒介，如 2D anime cel-shaded / 3D animated feature / painterly ink>,
<线条与上色方式>, <光影方式>, <质感关键词>. NOT a photograph, not photorealistic."
```

同时定好配色表：每类场景的主色、辅色、点睛色，写成 HEX。

### C2 角色设定卡（每个角色一张）

**文字卡**（固定描述，每次原样粘贴，不许改写）：
```
CHAR_<名字> = "<年龄>, <性别>, <民族/种族>, <发型+发色>, <标志特征>,
wears <固定服装>."
```
规则：
- 每个角色要有 **1 个从远处也能认出来的标志**（颜色、发型、配饰），让观众和模型都能区分
- 不用左右不对称的特征（单边发卡、胎记），一翻转就会出错
- 换装要单独写一套描述（如 `CHAR_A_校服`）

**图片卡**（⚠️ 强烈建议：只靠文字描述时，各镜头人物会出现换脸）：
- 正面 / 侧面 / 背面三视图 + 3–4 个常用表情，纯色背景
- 之后每次画图都把这张图当参考图一起传（模型支持多图参考时）
- 定稿后放进 `资产/角色/`，全剧不改

### C3 场景设定卡
每个反复出现的场景：一张空景定稿图 + 一段固定文字描述（布局、光源方向、时间段、天气）。

### C4 道具卡
关键道具（信物、武器、标志物）单独定稿，写清颜色和形状。

### C5 全局约定（写进圣经，全剧统一）
- 风向/雨向（例如一律向左）
- 主光源方向的习惯
- 人物站位习惯（例如主角在画面左侧，有助于观众记住）

## D. 分镜层

### 镜头表字段（每镜一行）
| 字段 | 说明 |
|---|---|
| 镜号 / 片中时间 / 生成时长 | 生成时长 = 片中时长 + 1 秒 |
| 景别 | 远 / 全 / 中 / 近 / 特写；相邻镜头尽量不要同一景别 |
| 机位角度 | 尽量少用正面平视；相邻镜头换角度 |
| 运镜 + 理由 | 固定 / 推 / 拉 / 横移 / 跟；**没有理由就用固定机位** |
| 人物位置、朝向、视线 | 左/右、眼睛落在 38% 或 62% 线上（竖屏则用上下三分线） |
| 首帧状态 | 动作开始之前的样子 |
| 动作（≤2） | 按发生顺序写 |
| 持续动态 | 风、雨、水、光、烟，低幅度 |
| 对白 / 旁白 / 字幕 | 谁说、说什么、几秒 |
| 声音卡点 | 动作要对上的音乐点 |
| 转场 | 硬切 / 动作匹配 / 声音桥接 |

### 构图检查
用色块草图检查构图，再转黑白看明暗：主体和背景的灰阶差最好 > 40（满分 255）。

---

## E. 静帧层（首帧 / 尾帧）

### E1 选哪种生成模式
| 模式 | 用在什么时候 | 风险 |
|---|---|---|
| 只给首帧 + 运动提示词 | 动作简单、结尾怎样都行 | 结尾不可控 |
| **首帧 + 尾帧** ✅ | 动作要有明确结果（坐下、靠肩、转头） | 首尾帧不一致会跳场 |
| 参考图 + 文字 ⚠️ | 模型支持多参考图时，用来锁住角色 | 不同平台的支持程度不一 |

### E2 静帧提示词通式（✅ 实测有效）

```
[镜头段] + [角色段 ×N，原样粘贴] + [场景段，原样粘贴] + [STYLE] + [NO_TEXT]
```

**镜头段**按以下顺序写：
```
1  <景别>, <9:16 vertical / 16:9 widescreen>.
2  Camera <机位>, <角度>, NOT <不要的角度>.
3  <角色A的称呼> <在画面中的位置 LEFT/RIGHT/CENTER>, <姿势>, <视线方向>, <表情>.
4  Eyes on the <38%/62%> line.
5  Their postures differ clearly: <A 怎样>, <B 怎样>.        ← 防止所有人同时动
6  In the BACKGROUND, <旁观者>, facing <主体>.               ← 反应位要提前摆好
7  Empty space <头顶 / 动作方向>.                            ← 给动作留空间
8  <光源方向与色温>. <风向：everything drifts toward the LEFT>.
9  No <多余物件 1>, no <多余物件 2>.                         ← 排除项
```

**尾帧**在首帧的基础上：
```
Same camera, same framing. <只写变化的那一个动作的结果>.
<不变元素逐项写> IDENTICAL to the first frame.
```

**固定段**：
```
NO_TEXT = "Absolutely no text, no letters, no numbers, no signs, no watermark, no logo,
no subtitles anywhere in the image."
```

### E3 改图通式：图生图（✅ 本次最重要的经验）
**尾帧不要单独画，要以首帧（或尾帧）为底图改出来**。这样背景一定一致。

```
Edit ONLY <要改的那一处，写具体到部位>.
<逐项列出要保持不变的：脸、视线、衣服、手、其他人物>.
CRITICAL — EVERYTHING ELSE IS FROZEN: keep the camera angle, framing, crop, the background
(<逐项点名背景元素>), the light direction and colour grading EXACTLY as in the input image.
Do NOT move, add, remove, resize or rearrange anything not named above.
<STYLE 简版>. <NO_TEXT>
```

每次只改一处；改多处就分成多次。

### E4 自动检查（脚本完成）
| 检查 | 方法 | 判定（经验值） |
|---|---|---|
| 首尾一致性 | 逐像素差异 + 九宫格分区 | 全图平均 >50 必跳场；约 15 且集中在要动的区域才算合格 |
| 手机尺寸可读性 | 缩到手机宽度（约 390px）看 | 远处人物要能看出是谁 |
| 边缘异物 | 四角、边缘放大 | 不能有多余的线或物件 |
| 文字/水印 | 放大检查 | 一律不允许 |

### E5 八条人工检查（✅）
1 动作要用到的道具，首帧里已经有　2 旁人的反应位摆好　3 多人姿势不雷同　4 动作留出空间
5 风向统一　6 手机尺寸看得清　7 没有多余物件　8 首尾帧叠加后，不该变的地方没变

外加：**左右对称的特征在首尾帧里都要看得见**（例如双辫只露一根，视频里就会"长出"另一根）。

### E6 独立审核
另开一个 agent（或另一个人）：只给图、要求文件和运动提示词，**不给你自己的结论**。
输出按 P0/P1/P2 分级，每条附依据，最后给"可以提交 / 先改 + 最小改法"。**P0 不清零，不提交。**

## F. 动态层（图生视频）

### F1 运动提示词通式（✅）
**只写"怎么动"，不再描述画面内容。**

```
<主体> <动作1>, then <动作2>.              ← 按时间顺序，最多 2 个
<其他人> does not move at all.              ← 一定要写谁不动
<环境小动态：hair / grass / water / rain stir slightly>.
<光线> stays constant.
The camera <stays fixed / slowly pushes in / tracks sideways>.   ← 要和首尾帧的构图一致
Same place, same background throughout, no cut, no scene change.
<不说话的镜头：Nobody opens their mouth.>
No text in the image.
```

运镜和首尾帧的关系：
- 首尾帧构图相同 → 只能写 `fixed`
- 尾帧景别更大 → 写 `pulls back`
- 尾帧景别更小 → 写 `pushes in`

### F2 参数（以火山方舟 Seedance 为例，✅）
```json
{"resolution": "720p", "ratio": "adaptive", "duration": 6,
 "watermark": false, "generate_audio": false,
 "content": [text, first_frame, last_frame]}
```
费用 ≈ 秒数 × 宽 × 高 × 帧率 ÷ 1024 ÷ 1000 × 每千 tokens 单价。

### F3 提交纪律
`dry-run` 打印费用和提示词 → 报价 → 获批 → **先试一镜** → 没问题再批量。全部请求写进 jsonl 日志（时间、任务 ID、费用、结果）。

### F4 常见拒收与应对
| 报错 | 应对 |
|---|---|
| 可能含真人（PrivacyInformation） | 画风往动画方向偏；用图生图"降写实"，只改质感、几何不动 |
| 模型未开通 | 到控制台开通 |
| 内容不合规 | 改写动作或景别，避开敏感画面 |

### F5 逐帧审片（✅）
```bash
# 每 0.25 秒一帧，拼成一张帧条
ffmpeg -i 镜.mp4 -vf "fps=4,scale=320:-1,drawtext=text='%{pts\:flt}':...,tile=6x4" -frames:v 1 帧条.png
# 自动检测跳场
ffmpeg -i 镜.mp4 -vf "select='gt(scene,0.2)',showinfo" -f null -
```
记录三件事：可用区间、关键动作发生在第几秒（剪辑卡点要用）、有没有变形或换脸。
可用区间够用就剪掉坏的部分；不够用就回到 E 修首尾帧，**只重拍这一镜**。

## G. 声音层

### G1 配音 / 对白
- 每个角色固定一种音色和语速，写进角色卡
- 免费方案：edge-tts（✅，需要能访问微软服务）；付费方案：各平台的 TTS 或声音克隆（⚠️ 声音克隆要有授权）
- 用 `silencedetect` 量出每句真正发声的起止时间，用来精确对位和定字幕时长
- **台词长度要匹配镜头长度**：中文约 4–5 字/秒，太长就删字，或者把镜头拆开

### G2 口型同步（⚠️ 对白多的漫剧需要）
- 方案一：拍侧脸、背影或远景，回避口型（最省钱）
- 方案二：先生成不说话的视频，再用口型同步模型对上配音
- 方案三：用自带音频驱动的视频模型
- 不管哪种方案，都先拿一镜试效果和价格

### G3 配乐卡点（✅）
1. 用公有领域或已授权的曲子
2. 用 ffmpeg 测响度曲线（`astats` 每 0.5 秒），找出强音、低谷和渐弱的位置
3. 切出候选段落给人试听，选定
4. 把强音时间写成卡点表：关键动作对强音，情绪转场对低谷，结尾对渐弱
5. 自由速度的曲子按实测强音来卡；节拍稳定的曲子才按 BPM 算

### G4 音效 ⚠️
脚步、开门、雨声之类，做成单独的音轨，按画面时间放置，音量低于对白。

## H. 合成层（脚本化，✅）

一条 ffmpeg filter_complex 完成：
| 环节 | 做法 |
|---|---|
| 剪 | 每镜 `trim` 可用区间，按卡点挪动入点；不够长就用 `tpad` 定格补 |
| 转场 | 默认硬切；情绪转场可以用 0.3–0.5 秒的 `xfade` |
| 字幕 | `drawtext` + 中文字体，竖屏 48–56px / 横屏 40px，白字黑边，0.25 秒淡入淡出；**跟着人声走，不跨镜头切点** |
| 对白 | 每句 `adelay` 放到位置 → 混成一条人声轨 → `loudnorm` 到 -16 LUFS |
| 配乐 | 打底 -24 LUFS，用 `sidechaincompress` 在人声出现时自动压低 |
| 收尾 | `alimiter` 防爆音 → **`aresample=48000`**（loudnorm 会把采样率带到 96k） |
| 片头/片尾 | 黑场 + 标题 / 下集预告 / 账号水印（由后期叠加，不让 AI 生成） |

### 导出检查
时长对、编码为 H.264 + AAC 48kHz、整体约 -16 LUFS（短视频平台可以到 -14）、峰值 < -1 dBFS、完整解码无报错、另截一帧作封面。

## 附录 2：按题材调整的参数

| 题材 | 画风建议 | 节奏 | 运镜 | 光线/色彩 | 特别注意 |
|---|---|---|---|---|---|
| 甜宠/恋爱 | 2D 日系 / 3D 动画 | 中慢，靠情绪点推进 | 推近、固定 | 暖色、柔光、逆光边缘光 | 肢体接触是高风险，多用反应镜头 |
| 悬疑/惊悚 | 写实 CG / 暗调 2D | 快切，钩子密集 | 慢推、低机位 | 冷色、硬光、大面积暗部 | 暗部容易出噪点，主体亮度要保证 |
| 古风/仙侠 | 国风厚涂 / 水墨 | 中速 | 横移、仰拍 | 青绿金、雾气 | 服饰纹样容易漂移，要定稿成服装卡 |
| 科幻/末日 | 写实 CG | 中快 | 拉远、环绕（慎用） | 霓虹或荒漠色 | 屏幕和 UI 文字一律后期加 |
| 搞笑/沙雕 | 2D Q 版 | 快，卡点重 | 固定 + 急推 | 高饱和 | 表情要夸张，靠音效和剪辑出笑点 |
| 动作/战斗 | 2D 动漫 / CG | 快切 | 跟拍、甩镜 | 高对比 | 动作拆成单动作的镜头，用剪辑拼出连贯感 |
