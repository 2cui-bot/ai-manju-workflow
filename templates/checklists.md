# 检查清单

## A. 立项（一次）
- [ ] 平台、画幅（9:16 / 16:9）、单集时长、每镜时长
- [ ] 画风方向、配色表
- [ ] 预算：`单集成本 ≈ 镜头数 × (张数×单价 + 秒数×每秒价) × 1.3`
- [ ] 音乐来源合规（公有领域 / 已授权）；不用真人脸，不仿现成 IP

## B. 剧本定稿前
- [ ] 0–3 秒有钩子，结尾有悬念
- [ ] 每镜每人 ≤2 个动作，配角 ≤1 个
- [ ] 复杂动作（打斗、拥抱、手部特写）已拆镜或回避
- [ ] 画面里需要的文字（招牌、屏幕、书信）都改为后期叠加
- [ ] 台词长度 ≤ 镜头秒数 × 4.5 字

## C. 资产定稿
- [ ] STYLE 段定稿
- [ ] 每个角色：文字卡 + 三视图（+ 表情）
- [ ] 每个反复出现的场景：空景图 + 文字段
- [ ] 全局约定：风向、主光源方向、主角常用站位

## D. 每一镜（照抄打勾）
- [ ] 镜头段写好；角色段 / 场景段 / STYLE / NO_TEXT 原样拼接
- [ ] 尾帧由首帧图生图得到（或反过来）
- [ ] `check_frames.py`：全图差异 < 25，且差异集中在要动的区域
- [ ] 人工八条：道具在、反应位、姿势不雷同、留空间、风向、手机可读、无异物、叠加无错位
- [ ] 左右对称的特征在首尾帧里都看得见
- [ ] 独立审核，P0 清零
- [ ] 运动提示词：动作顺序、谁不动、运镜和构图一致、no scene change
- [ ] `gen_video.py --dry-run` 报价 → 获批 → 提交
- [ ] `contact_sheet.py`：无跳场，记下可用区间和动作时间点

## E. 每一集合成
- [ ] 配乐：`analyze_music.py` 找强音 → 试听 → 确认卡点
- [ ] 配音：`make_voice.py` → 字/秒合理 → 试听
- [ ] 时间线 JSON：入点对准卡点，字幕不跨切点
- [ ] `compose.py` 合成 → 检查时长、-16 LUFS 左右、峰值 < -1 dBFS、48kHz
- [ ] 封面、标题、下集预告

## F. 复盘
- [ ] 踩坑表更新
- [ ] 有效的提示词固化到模板
- [ ] 实际花费 vs 预算、重拍率
